# Mindshift - 2D Puzzle-Platform Game

## Project Overview

**Mindshift** is a 2D puzzle-platform game built with **React.js** and HTML5 canvas. The game features a minimalist design, allowing players to explore various levels while solving puzzles and collecting items.

## Features

- **Player Movement & Camera System**: The camera follows the player across levels larger than the canvas.
- **Custom Game Engine**: Handles game loops, rendering, and input.
- **Platform & Collision Detection**: Ensures smooth movement and interaction with platforms and obstacles.
- **Level System**: Players can advance through multiple levels, collecting items and solving puzzles.
- **Item Collection**: Players can collect items to unlock new levels and progress through the game.
- **Responsive Design**: The game is optimized for desktop and mobile devices.
- **Sound Effects**: Adds an immersive experience with sound effects for player movement and interactions.
- **Game Over & Victory Screens**: Displays game over and victory screens with options to restart or return to the main menu.
- **Game Controls**: Players can use keyboard keys to move the player character and interact with the game.
- **Game Menu**: Players can navigate through the game menu to start a new game, view instructions, or exit the game.
- **Instructions**: Provides players with instructions on how to play the game and navigate through levels.
- **Game Timer**: Tracks the time taken to complete each level and displays it on the victory screen.
- **Level Progression**: Players can advance through levels by collecting items and solving puzzles.
- **Game State Management**: Manages game states, such as the main menu, game over screen, and victory screen.
- **Game Loop**: Handles game updates, rendering, and input processing in a loop.
- **Game Rendering**: Renders game elements, such as the player character, platforms, obstacles, items, and backgrounds.
- **Game Input**: Processes player input, such as keyboard keys, to move the player character and interact with the game.
- **Game Physics**: Implements basic physics, such as gravity and collision detection, to simulate player movement and interactions.
- **Game Audio**: Adds sound effects for player movement, interactions, and game events to enhance the gaming experience.
- **Game Assets**: Includes game assets, such as images, sprites, and audio files, to create a visually appealing and engaging game.
- **Game Development**: Develops the game using HTML5 canvas, JavaScript, and CSS to create a cross-platform and interactive gaming experience.
- **Game Design**: Designs game levels, puzzles, and challenges to engage players and provide an enjoyable gaming experience.
- **Game Testing**: Tests the game for bugs, glitches, and performance issues to ensure a smooth and enjoyable gaming experience.
- **Game Deployment**: Deploys the game to a web server or hosting platform to make it accessible to players worldwide.
